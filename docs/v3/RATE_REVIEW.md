The active table is `src/virtualtissue_xenium/v3/data/ontology/kinetics_v3.json`, version **`v3-kinetics-3`**. This audit corrects scientific descriptions and maps references to the implemented events. It changes **no numerical parameter**: all 91 hazards, 91 row-level beta values and six action-level beta defaults are identical to `v3-kinetics-2`. Eight reference identities and their stated endpoints were checked online: seven primary research papers and one review. Thirteen hazard rows have related contextual anchors; 78 have no mapped quantitative study. A contextual anchor is not an estimate of the row's parameter. `bibliography_verified: true` verifies reference identity; `parameter_estimated_from_cited_data: false` and `numerical_rate_verification` explicitly deny numerical calibration. `verify: true` retains unresolved quantitative applicability. Access limits are recorded per source; abstract access is not full-text verification.

## What a rate means in this implementation

`hazard_per_hour` is a baseline **menu-action proposal hazard per model unit per hour**. The unit is one segmented-cell agent, one nucleus used as a cell proxy, or one occupied fixed bin in the lattice kernel. Nuclear measurements do not establish equivalence to whole-cell kinetics. Lattice hazards are applied per occupied bin without multiplication by fractional occupancy; lattice events cannot be reported as cell births/deaths.

The guidebook applies explicit overrides, QC, expression/beta and context modifiers. The runtime then applies state and target gates, the ACTIVATE signal ratio and cell-agent proliferation density factor. With effective hazards `h_a` and `H = sum(h_a)`, the local prior uses `P(a) = h_a/H * (1-exp(-H*dt))` and `P(REST) = exp(-H*dt)`; when `H = 0`, REST has probability one. This is a first-event competing-risk menu, not separate independent Bernoulli draws. Ongoing motion and implicit clocks can also act during the step. A proposal can fail at commit because of conflicts, same-round death or capacity limits.

| Action | Implemented event and conditioning | What the default does not measure |
| --- | --- | --- |
| PROLIFERATE | Attempt a daughter while retaining the parent; inherit its baseline evidence and state clocks. CD8 requires activation; NK, CD4 and Treg do not have this gate. Cell-agent density and capacity can limit growth. Lattice growth increments a compatible existing neighboring bin. | Cell-cycle duration, Ki67 fraction or net population doubling. |
| ACTIVATE | Set/renew the activated flag and sample its lifetime. Rate multiplier: `(1+incoming signal)/(1+incoming suppressive signal)`. Restimulation is allowed. | Antigen detection, neuronal firing or measured protein activation. |
| EXHAUST | Set a binary exhausted flag, only when activated and not already exhausted. | The multidimensional impairment measured in the CD8 source, or universal terminal differentiation. |
| RECOVER | Clear exhaustion before the separate terminal-duration cutoff. | Demonstrated reversibility or checkpoint-inhibitor efficacy. |
| SECRETE | Add one abstract signal unit; Treg contributes to the suppressive channel. Lattice secretion is per selected bin, without occupancy scaling. | Molecular flux, antibody production, cytokine concentration or suppressive potency. |
| APOPTOSIS | Mark an agent dead and leave a corpse; in lattice, empty its entire occupancy. | A death probability inferred directly from its transcript signature or one cell death per bin event. |
| KILL | Attempt one eligible local target death, requiring `can_kill`, declared recognition, activation and no exhaustion. Both CD8 and NK have permission. Lattice killing empties the target bin. | Unconditional killing throughput, cumulative contact time or NK kinetics measured in CTL experiments. |
| CLEAR_CORPSE | Remove an available local cell-agent corpse; unavailable in lattice. | Measured engulfment time or the separate corpse lifetime. |
| MOVE | Start/renew a movement episode; unavailable for fixed bins. Speed integrates over its active duration, including later steps without a new MOVE selection. | Speed, displacement per event or persistence duration. |

The independent default clocks already exist: activation half-life 48 h, terminal-exhaustion duration 168 h, corpse lifetime 72 h, movement speed 6 µm/h and mean persistence 1 h, and signal half-life 0.5 h. These settings are assumptions, not parameters validated by the eight anchors. Clock changes take effect at simulation boundaries. Exhaustion blocks KILL and eventually RECOVER; it does **not** globally block PROLIFERATE, ACTIVATE, SECRETE or MOVE. No 20-fold activated proliferation multiplier or default 0.08/h activated proliferation rate is implemented: with expression/context multipliers neutral and crowding disabled, activated CD8 and NK both use 0.004/h.

Current logging also limits interpretation: `move` events count displacement segments, not necessarily episode starts, and no dedicated secretion event is emitted at commit. Selected actions are available in `decisions.jsonl`. Jev pooling changes the final action distribution; with hidden prior, alpha is one. The kinetic table does not calibrate that distribution's time scale.

## Explicit extrapolations and remaining decisions

The row-level `evidence_mapping`, `event_semantics` and `extrapolations` fields make the following transfers visible: CD8 proliferation evidence attached to NK; CTL killing evidence attached to NK; and CD8 functional-impairment evidence attached to CD4, Treg and NK exhaustion. Five rows carry these additional lineage-transfer flags. Epidermal transit is also attached to epithelial, keratinocyte and melanocyte division without a matching event estimate. Ki67 evidence supplies context for malignant proliferation, not a conversion into its 0.006/h default. The human/mouse tissue profiles currently have no fitted hazard overrides; shared values are not organism- or tissue-specific calibration.

For the present hypothesis-generating scope, record the selected defaults/overrides and test whether each reported contrast survives plausible variation in the relevant rates, beta, state clocks and unsupported lineage transfers. Include beta-zero and the relevant spatial controls; keep prepared evidence fixed when comparing these assumptions. Define the tested ranges and criteria before selecting an attractive result. If a conclusion changes sign or disappears, narrow the claim or report that dependence. A disclaimer or an added citation does not resolve dependence on an unsupported mechanism.

If the intended claim requires quantitative timing, first obtain independent observations matching the model's population, event, exposure time and unit, then fit or bound the **effective** process including gates, death, conflicts and observation bias. Separate fitting from evaluation. `ln(2)/k` is only an algebraic pure-birth reference, and `1/k` is only an exponential waiting-time reference under its assumptions; neither is the observed doubling, clearance or killing time here. Without suitable independent evidence, retain the qualitative conditional claim and `assumed` status. Existing object labels are accepted with declared provenance; neither H&E nor new manual annotation review is a requirement of this rate audit.
